# Тендер-помощник (прототип)

ИИ-помощник для поставщиков, которые готовят заявки на **государственные закупки Казахстана**
([goszakup.gov.kz](https://www.goszakup.gov.kz), Правила осуществления государственных закупок, приказ МФ РК № 687)
и закупки **АО «Самрук-Қазына»**.

Сервис помогает не допустить типичных ошибок, из-за которых заявки отклоняют: ошибки в цене, техспецификация
не пункт в пункт с требованиями заказчика, недостоверные сведения о кадрах и опыте, пропущенные сроки и истёкшая ЭЦП.

> **Важно.** Сервис только готовит черновики документов. Он ничего не подаёт: заявку вы подписываете своей ЭЦП
> и подаёте сами на портале. ИИ может ошибаться — сверяйте всё с документацией закупки.

## Что умеет

1. **Лот.** Загрузка документации (PDF с текстовым слоем, DOCX, TXT) или вставка текста. Текст извлекается прямо в браузере (pdf.js, mammoth.js).
2. **Требования.** ИИ извлекает требования заказчика в структурированный список: категория, ключевое значение, «критично», источник. Плюс данные лота (номер, заказчик, сумма, сроки) и список рисков.
3. **Техспецификация.** ИИ составляет ответ поставщика на каждое требование пункт в пункт, на **русском или казахском**. Таблицу можно править. Автопроверка: все ли требования покрыты, остались ли плейсхолдеры `[…]`, нет ли размытых формулировок («или эквивалент», «не менее»).
4. **Цена** (без ИИ). Проверка арифметики, путаницы «цена за единицу / сумма за объём», НДС, превышения выделенной суммы; расчёт обеспечения заявки (конкурс и аукцион — 1%, запрос ценовых предложений — 3%, п. 104 Правил № 687).
5. **Чек-лист** документов по Правилам № 687 с отметками, контролем срока подачи и срока действия ЭЦП.
6. **Письма и КП.** Гарантийное письмо, сопроводительное письмо и коммерческое предложение (с суммой прописью) из реквизитов компании, на русском или казахском.
7. **Экспорт** в DOCX (docx.js) и PDF (печать браузера — кириллица и казахские буквы ә ғ қ ң ө ұ ү һ і отображаются шрифтами системы).

Переключатель **RU / ҚАЗ** в шапке задаёт язык создаваемых документов. Интерфейс на русском.

## Демо-режим

Без API-ключа работает демо-режим: вымышленный лот «Услуги по уборке помещений школы в Алматы» с заранее
подготовленными результатами на обоих языках и ценовым предложением с намеренными ошибками. Все данные примера
**вымышлены** и помечены как пример.

Как показать: откройте сайт → «Загрузить пример лота» → «Извлечь требования» → «Сформировать техспецификацию» →
пройдите шаги «Цена», «Чек-лист», «Письма и КП».

## Подключение ИИ

Настройки (⚙) → провайдер, модель, API-ключ. Подойдёт любой OpenAI-совместимый Chat Completions API:

| Провайдер | Base URL | Модель по умолчанию |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-5.4-mini` |
| xAI | `https://api.x.ai/v1` | `grok-4.7` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-5.4-mini` |

Названия моделей можно поменять на любые доступные вашему ключу. Кнопка «Проверить подключение» делает тестовый запрос.

## Конфиденциальность

- У прототипа **нет сервера**. Это статический сайт.
- API-ключ хранится **только в localStorage вашего браузера** и отправляется только на указанный Base URL.
- Файлы читаются в браузере и никуда не загружаются. Текст документации уходит только выбранному ИИ-провайдеру
  и только по нажатию «Извлечь требования» / «Сформировать техспецификацию».
- Реквизиты компании, отметки чек-листа и черновики сохраняются в localStorage. Кнопка в Настройках удаляет всё.
- Для пробы заведите отдельный ключ с лимитом расходов и не вводите ключ на чужом компьютере.

## Запуск локально

Нужен любой статический веб-сервер (модули ES не работают через `file://`):

```bash
cd ..                       # папка, в которой лежит tender-helper
python3 -m http.server 8765
# открыть http://localhost:8765/tender-helper/
```

Смоук-тест в headless Chrome (демо-режим, экспорт DOCX/PDF, загрузка файлов, ИИ-путь с подменённым API, мобильная вёрстка):

```bash
npm install
CHROME=/usr/bin/google-chrome npm test
```

## Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`: при пуше в `main` он копирует `index.html` и `assets/`
и публикует их через GitHub Actions. Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Все пути относительные, поэтому сайт работает по адресу вида `https://<пользователь>.github.io/tender-helper/`.
Можно обойтись и без Actions: **Source: Deploy from a branch → main → / (root)** (файл `.nojekyll` уже есть).

```

assets/css/styles.css      стили (адаптивные, печать)

assets/js/ai.js            запросы к OpenAI-совместимому API и промпты
assets/js/extract.js       извлечение текста из PDF/DOCX/TXT
assets/js/price.js         проверка ценового предложения (без ИИ)
assets/js/checklist.js     чек-лист по Правилам № 687
assets/js/letters.js       шаблоны документов RU/KZ
assets/js/export.js        экспорт в DOCX и печать в PDF
assets/js/demo-data.js     вымышленный пример лота и готовые результаты
assets/js/util.js          форматирование, сумма прописью RU/KZ, проверка БИН
assets/vendor/             pdf.js, mammoth.js, docx (локальные копии)

```

## Ограничения прототипа

- Сканированные PDF без текстового слоя не распознаются (нет OCR) — вставьте текст вручную или загрузите DOCX.
- Нет интеграции с API портала госзакупок (нужен токен Центра электронных финансов), нет поиска лотов.
- Ключ хранится в браузере — это нормально для личного прототипа, но не для публичного сервиса с оплатой:
  там запросы к ИИ нужно проксировать через свой сервер, а документы клиентов хранить на серверах в Казахстане.
- Не все провайдеры разрешают запросы из браузера (CORS) и поддерживают Chat Completions для всех моделей.
- Чек-лист и шаблоны писем — ориентир, а не юридическая консультация. Формы конкретной закупки важнее.
- С 01.01.2026 стандартная ставка НДС в РК — 16%, суммы в планах госзакупок указываются без НДС; калькулятор
  позволяет переключить режим, если в документации суммы указаны с НДС.
